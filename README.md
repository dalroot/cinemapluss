# وب‌سایت رسمی فروشگاه سینما پنبه (Panbeh Shop)

> سامانه ارائه خدمات نرم‌افزاری و راهکارهای هوشمند | دامنه رسمی: [cinemapluss.ir](https://cinemapluss.ir)

## درباره پروژه
این مخزن شامل صفحه لندینگ، کاتالوگ خدمات نرم‌افزاری، مستندات شرایط و قوانین، رویه استرداد وجه و نماد اعتماد الکترونیکی فروشگاه سینما پنبه می‌باشد.

## ساختار مخزن
* `index.html`: لندینگ پیج معرفی خدمات، تعرفه‌ها و بخش نماد اعتماد الکترونیکی
* `terms.html`: قوانین و مقررات، حریم خصوصی، رویه عودت وجه و فرآیند ثبت شکایات
* `CNAME`: اتصال دامنه اختصاصی `cinemapluss.ir`
* `.nojekyll`: تنظیمات بارگذاری مستقیم استاتیک
* `.github/workflows/deploy.yml`: پایپ‌لاین انتشار خودکار از طریق GitHub Actions

## استقرار و میزبانی
پروژه از طریق **GitHub Pages** و شبکه توزیع محتوای **Cloudflare** میزبانی و ایمن‌سازی شده است.
