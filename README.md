## تنظیمات DNS در کلودفلر (Cloudflare)
* **نوع CNAME:**
  * `Name`: `@` (یا `cinemapluss.ir`)
  * `Target`: `dalroot.github.io`
  * `Proxy Status`: **Proxied (ابر نارنجی)**
* **نوع CNAME برای ساب‌دامین www:**
  * `Name`: `www`
  * `Target`: `cinemapluss.ir`
  * `Proxy Status`: **Proxied (ابر نارنجی)**
* **بخش SSL/TLS:**
  * حالت روی **Full** یا **Flexible** تنظیم شود تا گواهی امنیتی HTTPS بلافاصله فعال گردد.
